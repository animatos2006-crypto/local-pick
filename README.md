# 로컬픽 (Local Pick)

카카오 장소 검색, 공공 상가 데이터, 네이버 보조 검색을 결합한 React 음식점·카페 지도 서비스입니다. 개인 가게 탐색, 조건 추천, 저장 목록, 현재 위치, 내부 길찾기를 제공합니다.

## 실행 방법

Node.js 20 이상이 필요합니다.

```bash
npm install
copy .env.example .env
npm run dev
```

`.env`에 사용할 API 키를 입력해야 실시간 검색이 동작합니다. 실제 `.env` 파일은 Git 또는 제출물에 공개하지 마세요.

프로덕션 빌드:

```bash
npm run build
npm run preview
```

## 데이터 안내

API 응답과 `src/data/stores.js`의 기본 데이터를 함께 사용합니다. API 제공 범위와 호출 제한 때문에 지도에 표시되는 결과가 해당 지역의 모든 매장을 의미하지는 않습니다. 영업 상태·주소·메뉴는 실제 정보와 다를 수 있으므로 방문 전에 확인해야 합니다.

매장 데이터에 `isOpen: true/false`가 있거나 `openingHours`가 있으면 현재 영업 상태를 계산해 표시합니다. `openingHours`는 일요일부터 토요일까지의 배열이며, 각 값은 `09:00-22:00`, 여러 영업 구간의 배열 또는 `closed`를 사용할 수 있습니다. 영업시간 정보가 없는 매장은 상태를 추정하지 않습니다.

실서비스 전환 시 데이터 계층을 다음과 같이 교체할 수 있습니다.

1. 장소 검색 API에서 상호명·좌표·카테고리 조회
2. 지방행정 인허가 데이터에서 업소명·주소·영업 상태 조회
3. 주소와 상호명을 정규화하여 중복 매칭
4. 인허가 데이터에만 존재하는 영업 업소를 `hidden`으로 분류
5. 좌표가 없는 인허가 주소는 Geocoding API로 변환

`source` 값은 다음 의미를 갖습니다.

- `hidden`: 공공 인허가 데이터에서만 확인된 숨은 가게
- `verified`: 공공데이터와 장소 검색 양쪽에서 확인
- `place`: 장소 검색 데이터에서 확인

## 주요 파일

- `src/App.jsx`: 검색, 지도, 추천, 저장 및 전체 UI
- `src/data/stores.js`: 지역과 시연용 매장 데이터
- `src/hooks/useLocalStorage.js`: 컬렉션 영속성
- `src/styles.css`: 반응형 디자인

## 기술 구성

- React
- Vite
- React Leaflet / OpenStreetMap
- Lucide React
- LocalStorage

지도 타일을 표시하려면 인터넷 연결이 필요합니다. 저장 데이터는 사용자의 브라우저에만 보관됩니다.

## 환경 변수

- `KAKAO_REST_API_KEY`: 장소 검색과 길찾기
- `PUBLIC_DATA_SERVICE_KEY`: 소상공인 상가 데이터
- `NAVER_API_HUB_CLIENT_ID`: 네이버 지역 보조 검색
- `NAVER_API_HUB_CLIENT_SECRET`: 네이버 지역 보조 검색
- `SEOUL_SUBWAY_API_KEY`: 서울시 실시간 열차 위치

## 제한 사항

- 저장 데이터는 `localStorage`에 저장되어 기기 간 동기화되지 않습니다.
- 리뷰 많은 순은 네이버가 반환하는 최대 5개 결과에만 적용됩니다.
- 지도 위 버스·지하철 이동 아이콘은 실제 위치가 아닌 경로 안내 애니메이션입니다.
- 서울시 실시간 열차 위치는 지원 노선에서 현재 역 기준으로 표시되며, 정확한 GPS 좌표가 아닙니다.
